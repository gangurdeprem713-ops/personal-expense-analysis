# personal-expense-analysis
Analyzed personal UPI transaction data using Python and built a Power BI dashboard'

## Overview
Analyzed my personal 1-year UPI transaction data (PhonePe) to understand spending patterns and categorize expenses automatically using Python.

## Tools Used
- Python (Pandas)
- Google Colab
- Power BI

## What I Did
1. Cleaned raw transaction statement data (removed sensitive information)
2. Built a keyword-based function to automatically categorize 700+ transactions into categories (Food, Groceries, Education, Medical, etc.)
3. Analyzed total spend by category
4. Built an interactive Power BI dashboard to visualize spending patterns

## Key Insights
- Highest spend category: Personal Transfers (78%)
- Second highest: Education (14%)
- Regular small expenses: Food and Groceries

## What I Learned
- Data cleaning and preprocessing with Pandas
- Writing rule-based text classification functions
- Data visualization with Power BI
- Handling real-world messy data
